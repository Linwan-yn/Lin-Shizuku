Lin-Shizuku 是什么？
 
基于 Shizuku 13.5.4 与 Sui 深度定制的授权管理工具，在原版基础上新增了大量实用功能，让手机更好用。
 
核心功能：
 
- 三种启动方式：无线调试（无需电脑）、连接电脑 ADB、Root 直启
​
- 开机自启：支持开机广播、预热、Root 脚本三种模式，重启后自动恢复授权
​
- 无线调试断WiFi不断服务：切换 TCP 模式后，断开 WiFi 服务依然运行
​
- 高刷新率：自动识别设备最高刷新率并锁定
​
- 应用授权管理：一键管理应用的使用情况访问、悬浮窗等权限
​
- 电池优化白名单：防止后台被系统杀死
​
- 进程守护：双进程互守，崩溃自动恢复
​
- 内置浏览器：无需跳转外部浏览器即可下载更新
​
- 检查更新：进入应用自动检测新版本，内置下载器一键安装
 
和原版 Shizuku 的区别：
 
原版只提供授权服务本身。Lin-Shizuku 在保留原版全部功能的基础上，加了无线调试自启、刷新率锁定、电池白名单、进程守护、内置浏览器、自动更新等系统级优化，开箱即用，不需要额外装其他工具。
